# Code Graph技能需求文档

## 需求背景
作为一个有一定技术基础的产品经理，在vibe coding时经常需要评估AI生成的代码是否符合逻辑。但代码读起来太复杂，往往不知从何入手。需要有一个工具可以对已有代码仓库进行扫描，提取其中关心的关键流程，生成流程图/时序图，方便梳理调用逻辑/消息时序等。希望能够有一个图形化的工具可以显示这些流程，并支持可视化的交互，方便快速在代码中定位到某个调用过程。

## 需求描述
 - 创建技能（SKILL）以方便在Claude Code等Agent中生成Code Graph
 - 通过SKILL.md指引AI Agent阅读代码库，定位用户所关注的流程，生成结构化的CodeGraph数据（包括流程图和时序图，例如Mermaid格式，要求记录关键代码位置）
 - 基于生成的Graph数据，使用脚本生成一个可交互的单页面网页，可以以流程图/时序图的模式查看所关注的流程。该图支持点击查看相应的代码（通过预定义的IDE工具，定位到代码文件和行号）。
 - 允许配置代码查看工具


## 工作流说明
 - 当用户需要查看代码中某流程的流程图/时序图时触发此技能
 - 与用户沟通以明确用户的需求（关注哪部分的流程，明确范围、深度、广度、粒度、确定表现形式：流程图/时序图/都需要）
 - 如果用户没有指定过编辑工具，需要让用户指定个编辑工具（需要检查该工具是否已经安装且可用）
 - 如果用户已经指定了编辑工具，则开始阅读用户关注的代码库，深入了解相关流程的调用细节。
 - 按照与用户沟通明确的信息生成结构化的流程图/时序图 即CodeGraph数据（例如mermaid格式？ 需要明确记录所涉及的代码位置：文件+行号， 记录图中所需必要的属性信息）
 - 当CodeGraph生成完成后，需要先用一个脚本校验一下格式是否正确。如存在问题则需要Agent进行修改，直到格式正确。
 - 完成格式校验后，使用脚本+模板生成一个单页的html页面，以可视化展示所生成的CodeGraph，要求：
 	- 页面顶部可以切换不同的Graph类型（流程图/时序图）
 	- 页面画布展示所选的CodeGraph， 支持zoom & pan
 	- Graph中的元素（流程节点、箭头、文字等）均支持hover和点击。 hover时要高亮该元素。点击时使用用户指定的IDE工具打开该元素对应的code页面并定位到相关位置。
 - 每次使用该技能都生成一个独立的页面，不要覆盖之前生成的内容。


## 补充要求
 - CodeGraph数据必须由AI Agent来生成。不要尝试使用代码直接提取。
 - 不要直接使用mermaid生成的SVG，需要用类似的方式在画布上绘制流程图和时序图。并完美支持元素颗粒度的hover、点击事件。
 - 生成的页面为一个单独的html文件，不依赖其他脚本、后台服务。
